## TIER 1 — BUILD FIRST (extreme traffic × extreme earning, all client-side)

1. **Passport Photo Maker (#170)** — Pi7's #1 "Most Used" tool; huge commercial intent (paid to download/print sheets = 5-star earning). Presets: 2x2 (US), 35x45 (visa), 3.5x4.5, 600x600 upload. Reuses existing crop/resize/rotate + canvas.
2. **Reduce Image Size to Exact KB (#171)** — "compress image to 100KB / 200KB / 50KB" is a top long-tail (Pi7's biggest cluster). Brute-force quality slider until target hit. Trivial client-side loop.
3. **Word/Excel/PPT → PDF (#172)** — iLovePDF/CloudConvert flagship; 900K+/mo. Use browser `print-to-PDF`/pdf-lib for repacks; documents rendered via in-page iframe → PDF.
4. **Compress PDF to KB (#174)** — "pdf to 50kb/100kb/200kb" huge long-tail (Pi7/FreeConvert). Reuse existing pdf-compressor engine with quality pump.
5. **MP4 → MP3 (#176)** — 900K+/mo; ffmpeg.wasm already bundled in plugin. Standalone high-volume SEO page.
6. **Video Compressor to MB (#175)** — ffmpeg.wasm; exact-size target loop (squeeze-by-bitrate).
