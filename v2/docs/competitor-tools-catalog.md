## Consolidated Summary

- **Image tools** dominate (compress, resize, crop, rotate, flip, convert, remove bg, upscale, meme).
- **PDF tools** are the #2 cluster (merge, split, compress, convert, protect, sign, OCR).
- **Pi7 leads on "exact size / ID / government" niches** (passport, PAN card, KB targets, DPI) that other sites ignore.
- **CloudConvert leads on format breadth** (esp. documents, archives, ebooks, audio, video).
- **AI/2026 fastest growing:** remove background, upscale, photo enhancer, OCR, AI summarizer, translate — all server/AI dependent.
