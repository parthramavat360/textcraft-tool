A comprehensive suite of 39+ free text, image, and media tools built as native Elementor widgets.

== Description ==

TextCraft Tools adds 39+ powerful Elementor widgets across six categories:

**Case Converters**
* Case Converter (UPPERCASE, lowercase, Sentence, Title, Capitalized, aLtErNaTiNg, InVeRsE)
* Sentence Case Converter
* Title Case Converter

**Text Cleaners**
* Character Remover
* Duplicate Line Remover
* Duplicate Word Finder
* Em Dash Remover
* Remove Line Breaks
* Remove Text Formatting
* Remove Underscores
* Whitespace Remover
* Plain Text Converter

**Text Generators**
* APA Format Generator
* Invisible Text Generator
* Online Notepad
* Repeat Text Generator
* Reverse Text Generator
* Roman Numeral Date Converter
* Word Cloud Generator

**Random Generators**
* Random Choice Picker
* Random Date Generator
* Random IP Generator
* Random Letter Generator
* Random Month Generator
* Random Number Generator
* Password Generator
* UUID Generator

**Translators & Counters**
* Find and Replace Text
* NATO Phonetic Alphabet
* Sentence Counter
* Phonetic Spelling Tool
* Pig Latin Translator
* Sort Words Alphabetically
* Wingdings Translator
* Word Frequency Counter

**Image & Media**
* Image to ASCII Art
* Image to Text (OCR via Tesseract.js)
* JPG to PNG Converter
* JPG to WebP Converter
* Online Video Converter (FFmpeg.wasm)

All tools run **entirely in the browser** — no data is ever sent to any server.

== Installation ==

1. Upload the `textcraft-tools` folder to `/wp-content/plugins/`.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Ensure **Elementor** (free or Pro) is installed and activated.
4. Open any page in the Elementor editor and find the **TextCraft Tools** category in the widget panel.

== Frequently Asked Questions ==

= Does the plugin require Elementor Pro? =
No. The free version of Elementor is sufficient.

= Is any data sent to external servers? =
No. All text and image processing runs locally in the visitor's browser using JavaScript. The OCR widget loads Tesseract.js from a CDN, and the video converter loads FFmpeg.wasm from a CDN — no user data is transmitted.

= Can I use shortcodes instead of Elementor widgets? =
This plugin is designed exclusively as an Elementor widget suite and does not provide shortcodes.
